# Bucket de Scoop de Ecuafact

Manifiestos de [Scoop](https://scoop.sh) para instalar el CLI `ecuafact` en Windows.

```powershell
scoop bucket add ecuafact https://github.com/Ecuanexus/ecuafact-scoop
scoop install ecuafact/ecuafact-preview
ecuafact --version
```

Actualizar: `scoop update ecuafact-preview`. Desinstalar: `scoop uninstall ecuafact-preview`.

Documentación del CLI: <https://docsapi.ecuafact.com/v1/guias/cli>.
